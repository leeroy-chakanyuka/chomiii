# Writing

1. Identify audience, purpose, requested tone and must-keep facts.
2. Preserve the user's meaning, language and level of formality; do not add fabricated achievements, dates or endorsements.
3. Lead with the point. Use natural wording, specific details and readable length.
4. Produce a ready-to-use draft; label placeholders only when a required fact is unknown.
5. Revise when feedback is provided rather than defending the first version.
6. Do not imply the text was sent, published or shared; generating text is not delivery.

For sensitive or consequential communications, flag assertions the user should verify before sending.
