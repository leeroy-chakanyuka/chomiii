# Summarization

1. Identify the user's purpose: quick recap, decision brief, study notes or meeting actions.
2. Represent only what the supplied material supports. Distinguish direct statements from reasonable inferences.
3. Retain constraints, decisions, dates, owners, numbers and unresolved questions.
4. Avoid repetition, unnecessary quotation and fabricated context.
5. If material is incomplete, state exactly what is missing; do not pretend to have read a missing attachment or external link.
6. When action items matter, separate agreed actions from suggestions.

Aim for a summary a busy reader can trust without rereading the source.
